## 注文受付〜会計の処理フロー（補足）

```mermaid
flowchart TD
    A[SC03 注文受付] --> B{タンク残量を取得<br/>MAX updateNo の行}
    B --> C[販売可能商品 isDeleted=0 を一覧表示]
    C --> D[サイズ・数量を入力]
    D --> E{注文合計コーヒー量<br/> ≤ 残量 ?}
    E -- No --> F[エラー: 残量不足]
    F --> D
    E -- Yes --> CP{クーポン適用?}
    CP -- あり --> CPV[利用可能クーポンを選択<br/>有効期間内 / 小計≥minSubTotal]
    CP -- なし --> G
    CPV --> G[課税対象=小計−値引<br/>消費税=floor 課税対象×0.08<br/>合計=課税対象+消費税]
    G --> H[SC04 預り金入力→つり銭・最小金種表示]
    H --> I[(トランザクション)]
    I --> J[Sales へ1件INSERT]
    J --> K[SalesDetail へ商品分INSERT]
    K --> K2[Sales に couponNo・discount を記録]
    K2 --> L[Coffee へ 残量-使用量 を新規INSERT]
    L --> M{続けて注文?}
    M -- Yes --> A
    M -- No --> N[SC02 メニュー]
```

> 注：消費税は **8%・小数切り捨て**（Q&A項番1,2）。Item.price は税抜単価、Sales.total = subTotal + tax の外税モデルで扱う。
>
> クーポン適用時は **課税前値引き**：`課税対象 = subTotal − discount` → `tax = floor(課税対象 × 0.08)` → `total = 課税対象 + tax`。
> 1注文1枚・定額・注文単位。`subTotal` は値引き前グロスのまま保持し、`discount` を別列で記録する（閉店処理の集計整合のため）。詳細は `db/03_coupon.sql` / `db/README.md` を参照。
